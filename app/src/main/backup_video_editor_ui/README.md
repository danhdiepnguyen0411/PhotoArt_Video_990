# Giao diện Video Editor & Customizer (Tạo video kỷ niệm)

Thư mục này lưu trữ phiên bản giao diện dạng Editor màn kết quả video:
- Khung xem trước 9:16 có Fullscreen Dialog
- Card "Ảnh của bạn" (dải ảnh ngang, số thứ tự, nút Sắp xếp, nút Thêm ảnh)
- Card "Nhạc nền" (đổi nhạc, waveform âm thanh, preview)
- Card "Hiệu ứng chuyển ảnh" (dropdown chọn hiệu ứng mờ dần, switch áp dụng tất cả)
- Bottom bar cố định (thông số 24 giây • 9:16 • HD, nút Tạo video to)

- `layout/fragment_video_result.xml`
- `layout/item_result_photo_strip.xml`
- `layout/dialog_fullscreen_video.xml`
